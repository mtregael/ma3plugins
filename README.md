# ma3plugins
Plugins tools for MA3

##CueToRecipe: 
a plugin that convert a the cues of a sequence into recipe.
The script try to find the nearest Fixture Group of the cue and the associated Preset. It add a Standard Recipe, delete old values and Cook the recipe.
As a busking user, i use this script to convert the sequence that i have created in live during show. 
It shouldn't work properly on complex cues as it only look for one approching Fixture Group. It is still in testing.
